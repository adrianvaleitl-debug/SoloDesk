# SoloDesk brand system
- Product: SoloDesk
- Current version: V3.3
- Tagline: Your business, in one place.
- Creator attribution: Created by Adrian Vale
- Creator links: YouTube @Adrianvaleitl · TikTok @adrianvaleitl · Ko-fi marketinsight
- Visual reference: Independent SoloDesk identity, sharing only the quality and usability standards of Market Insight
- Default website/app appearance: dark navy and slate surfaces, cool blue accents, rounded but distinct workspace components
- Base colours: #0D1420 background, #151F2D panels, #1C2A3B raised panels, #2A3A50 borders, #EFF5FF text, #9AAAC0 muted text
- Default accent: #B8D8FF; secondary accent: #6F9FE0
- Radius system: 11–13px controls, 18–19px cards, 22–24px hero panels
- Themes: Ocean, Sage, Violet, Coral, Teal
- Fonts: Segoe UI, Arial, Verdana, Trebuchet MS, Georgia
- Typography: bold by default, user-selectable regular weight
- Voice: calm, capable, clear, practical
