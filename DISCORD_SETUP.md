# SoloDesk Discord setup pack
A Discord server still needs to be created by an account owner. Suggested structure:

## START HERE
- #welcome — product purpose and links
- #announcements — official release news
- #download-and-install — verified downloads and setup guide
- #changelog — version changes

## COMMUNITY
- #general
- #ideas-and-feedback
- #help-and-support
- #bug-reports

## TEAM (private)
- #staff-room
- #release-checklist

## Roles
Owner, Administrator, Moderator, Early Tester, SoloDesk User

Never post passwords, payment details or private customer information. SoloDesk is an organiser, not accounting, tax or legal advice.
